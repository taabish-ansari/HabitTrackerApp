# HabitTrackerApp

A clean, production-minded rebuild of the HabitTracker application.

## Rebuild goals
- React + Vite frontend
- Express + Node.js backend
- Supabase Auth + PostgreSQL
- Reliable habit completion, streak, XP, and badge logic
- User-isolated data and secure authorization
- Analytics dashboard
- Clean separation between UI, state, API, and domain logic
- No legacy SQLite/custom-auth code

The original `HabitTracker-App` repository remains untouched and is being used as a reference for the rebuild.
